Activity Diagram Alur Fungsional Sistem

Rincian langkah interaksi antara Pengguna dan Sistem pada SIAKAD SMPN 1 Trimurjo

14 Alur Fungsional
Alur Sistem 01 TU / Admin

Dashboard Administrator

  1. User masukkan email & password
  2. Sistem memvalidasi kredensial
  3. Tampil menu Dashboard Admin
  4. Menampilkan ringkasan info data akademik
Alur Sistem 02 TU / Admin

Pengelolaan & Input Data Siswa

  1. Pilih menu Data Siswa
  2. Klik tombol Siswa Baru
  3. Isi formulir lengkap (94 field Buku Induk)
  4. Klik Buat / Simpan
  5. Sistem menyimpan data & tampil ke daftar
Alur Sistem 03 TU / Admin

Pengelolaan & Input Data Guru

  1. Pilih menu Data Guru
  2. Klik Guru Baru & isi NIP, Nama, dll.
  3. Klik tombol Buat / Simpan
  4. Sistem menyimpan ke basis data
Alur Sistem 04 TU / Admin

Pengelolaan Data Kelas & Wali Kelas

  1. Pilih menu Data Kelas
  2. Klik Kelas Baru (VII A, tingkat, dll)
  3. Pilih guru sebagai Wali Kelas
  4. Klik Buat & simpan ke database
Alur Sistem 05 TU / Admin

Pengelolaan Periode Tahun Ajaran

  1. Pilih menu Data Tahun Ajaran
  2. Klik Tahun Ajaran Baru
  3. Input tahun (contoh: 2025/2026) & status
  4. Klik Buat & sistem menyimpan data
Alur Sistem 06 Wali Kelas

Dashboard Wali Kelas

  1. Walas login ke sistem
  2. Sistem memvalidasi kredensial
  3. Tampil dashboard ringkasan: jadwal, data siswa rombel, dan rekap nilai
Alur Sistem 07 Wali Kelas

Penyusunan Jadwal Pelajaran Kelas

  1. Pilih menu Jadwal Pelajaran
  2. Klik Jadwal Baru
  3. Pilih mapel, guru, hari, jam, kelas
  4. Klik Buat / Simpan
Alur Sistem 08 Wali Kelas

Monitoring Data Siswa Binaan

  1. Pilih menu Data Siswa
  2. Sistem menampilkan daftar siswa binaan
  3. Melihat identitas & profil lengkap siswa
Alur Sistem 09 OUTPUT UTAMA

Rekapitulasi & Cetak Leger Nilai

  1. Pilih menu Nilai Siswa
  2. Sistem merekap nilai seluruh mapel kelas
  3. Klik tombol Cetak Leger
  4. Dokumen dicetak & diserahkan ke TU
Alur Sistem 10 Guru Mapel

Dashboard Guru Pengampu

  1. Guru login ke sistem
  2. Sistem menampilkan dashboard guru: jadwal mengajar, siswa, dan nilai
Alur Sistem 11 Guru Mapel

Pemeriksaan Jadwal Mengajar

  1. Pilih menu Jadwal Pelajaran
  2. Sistem menampilkan daftar jadwal mengajar sesuai mapel & kelas
Alur Sistem 12 Guru Mapel

Data Siswa Rombel yang Diajar

  1. Pilih menu Data Siswa
  2. Melihat daftar siswa pada rombel yang diajar
Alur Sistem 13 Guru Mapel

Input Nilai & Capaian Belajar Siswa

  1. Pilih menu Nilai Siswa ➡️ Nilai Baru
  2. Input nilai: Pengetahuan, Keterampilan, Sikap (`sb/b/c/k`), Deskripsi
  3. Klik Buat / Simpan
Alur Sistem 14 Siswa

Akses Mandiri Siswa

  1. Siswa login menggunakan NISN / Email
  2. Sistem memvalidasi kredensial
  3. Menampilkan: Nilai Hasil Belajar, Data Siswa, & Jadwal Pelajaran

Arsitektur Class Diagram & Struktur Relasi Basis Data

Relasi 13 tabel basis data MySQL yang telah disempurnakan dan terpasang di phpMyAdmin

Status: Database Aktif
users Autentikasi
🔑 id_user (PK, BIGINT)
name (VARCHAR 255)
email (VARCHAR 255, UNIQUE)
password (VARCHAR 255)
remember_token, timestamps
siswas (94 Field) Buku Induk
🔑 id_siswa (PK, BIGINT)
🔗 user_id (FK ke users)
🔗 kelas_id (FK ke kelas)
nis (VARCHAR 50), nisn (VARCHAR 50)
nama, jk, ttl, agama, alamat
data_ayah, data_ibu, data_wali
presensi, ekstrakurikuler, foto...
nilais Rapor & Leger
🔑 id_nilai (PK, BIGINT)
🔗 siswa_id (FK ke siswas)
🔗 jadwal_id (FK ke jadwal)
🔗 tahun_ajaran_id (FK)
semester (ENUM 'ganjil', 'genap')

nilai_sikap ('sb','b','c','k')
nilai_akhir, deskripsi (TEXT)

tingkat (7, 8, 9)
🔗 guru_id (FK - Wali Kelas)

nip, nama_guru, no_hp, alamat
🔗 user_id (FK ke users)
